# HoMoW · 3D-бета 0.8.0

Єдина сторінка бети: https://reformoti.github.io/Hold-Monster-World/beta/

Основна гра, сервер і база даних не змінюються. Всі зміни цього переносу знаходяться в `beta/`. `build.py` створює клієнт та інтерфейс з поточних оригінальних модулів, замінюючи тільки 3D-відображення, введення та шлях збережень. Всі ціни, характеристики, нагороди й прогрес залишаються в оригінальній симуляції.

Це розширена робоча бета, а не завершений повний перенос. Збереження серверних акаунтів і повна мережева відповідність не заявляються. Поточна 2D-версія залишається незмінною. Для бети використовується `homow_beta_full_v1`; за першого запуску може читатися копія доступного локального `brukivka_realms_v1`. Ключ основної гри не перезаписується. Бета-налаштування окремі.

## Побудова та перевірки

```
python3 beta/build.py
node --test beta/world.test.cjs
npm test
```

`index.html`, `client.js`, `options.js`, `music.js`, `skills.js`, `release.js` генеруються. Правити генератор та вихідні адаптери, потім запускати побудову. Оригінальні файли за межами `beta/` не редагуються.

Тести DOM і програмного 3D не замінюють огляд WebGL у браузері. Показники FPS не слід заявляти без реального вимірювання. Для вимірювання є параметр `?perf=1` та дані `#homowPerformance` у DOM.

Оновлення 0.7.0: торговці мають окремі цивільні моделі та професійні інструменти. Атака тільки ЛКМ; кнопка атаки прихована. На мінікарті прибрано текстову плашку, назва регіону залишається вгорі екрана.

## Світ 0.7.0

Нова нерегулярна забудова стартового села зі спільними видимими й фізичними координатами; прохідність до всіх торговців перевіряється. Кузня з димарем, башта мага, майстерня рун, бронниця, теплиця, реміснича майстерня, склад і відкритий ринок. Додано колодязь, телегу, горно, ліхтарі, лавку, дрова, бочки, ящики, мешканців і нову браму з вартовими. Рідкі декорації поза селом мають колізії стовбурів і каміння та не перекривають точки появи монстрів і ресурсів. Трава й декоративні квіти не додаються.

Для кожного канонічного типу ворога задано 3D-ідентичність із анатомією родини, окремою палітрою та деталями; еліти й боси мають додаткові ознаки. Для всіх типів ресурсів діють окремі палітри та геометрія; руди T1–T8 розрізняються кольорами й жилами, дерева — кронами й корою, кущі — листям та плодами. Кількості, ID, характеристики, винагороди й точки появи монстрів не змінюються.

0.7.1: програмний 3D використовує спрощені округлі меші та кеш проєкцій нерухомих об’єктів. Рух камери, зміна якості й виснаження ресурсу скидають кеш. WebGL зберігає повну геометрію.

## 0.8.0 · Краї, руди та хода

За краєм поточного кластера видно сусідній ландшафт. Зовнішній край світу оформлено береговими скелями, водою та далекими скелястими островами; за межі ігрової карти персонаж не виходить. Руди винесено за межі села й міста до вільних кам’яних ділянок, без перекриття входів і переходів; ID, тир, кластер і запаси зберігаються. Хода рахує кроки за реальною пройденою відстанню, зупиняє анімацію біля стін і плавно повертає візуальну модель. Згладжування відображення не змінює збережені координати; переходи між кластерами показуються одразу.
