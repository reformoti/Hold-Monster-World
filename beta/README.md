# HoMoW · 3D-бета 0.6.1

Єдина сторінка бети: https://reformoti.github.io/Hold-Monster-World/beta/

Основна гра, сервер і база даних не змінюються. Всі зміни цього переносу знаходяться в `beta/`. `build.py` створює клієнт та інтерфейс з поточних оригінальних модулів, замінюючи тільки 3D-відображення, введення та шлях збережень. Всі ціни, характеристики, нагороди й прогрес залишаються в оригінальній симуляції.

## Відповідність

| Оригінал | У 3D-беті | Перевірено |
|---|---|---|
| 12 кластерів, 141 монстр, 190 ресурсів, 3 підземелля | Ті самі вихідні дані, 3D-геометрія | Кількість, запуск симуляції й рендеру в тестах |
| Інвентар, екіпірування, сховище, торгівля, ремесло, таланти, контракти, досягнення, подорожі | Спільні вихідні модулі та оригінальні вікна | Відкриття вікон, базові перевірки оригіналу; повний ручний прохід ще потрібен |
| 6 родин зброї, 18 варіантів | 3D-моделі зброї; оригінальні характеристики | Рендер усіх варіантів, атаки в напрямку курсора |
| Усі оригінальні прийоми | Оригінальні формули з ручним напрямком | Виклик кожного прийому; колові прийоми залишаються коловими |
| Броня, друга рука, зовнішність, шоломи, скакуни | Броня за матеріалом, щит/фоліант/смолоскип, борода/шолом і 4 скакуни | Рендер скакунів; точна візуальна відповідність всіх деталей ще неповна |
| Монстри й боси | 3D-родини моделей, назви/HP/рівень, геометрія попереджень атак | Симуляція оригіналу; деякі зовнішності спрощені |
| Локальне збереження | Сумісний формат, окремий ключ бети, імпорт/експорт JSON | Вихідне збереження не перезаписується |
| Українська, музика, якість, роздільність, анімації | Українська; музика з оригінальної бібліотеки; параметри 3D | Тести запуску й шляхів ресурсів |
| Онлайн-акаунти, PvP, групи, рейтинги | Ще не підключено | Потребує окремої серверної інтеграції; поточний VPS не приймає напрямок прицілу і не віддає бета-клієнт |

Це розширена робоча бета, а не завершений повний перенос. Збереження серверних акаунтів і повна мережева відповідність не заявляються. Поточна 2D-версія залишається незмінною. Для бети використовується `homow_beta_full_v1`; за першого запуску може читатися копія доступного локального `brukivka_realms_v1`. Ключ основної гри не перезаписується. Бета-налаштування окремі.

## Побудова та перевірки

```
python3 beta/build.py
node --test beta/world.test.cjs
npm test
```

`index.html`, `client.js`, `options.js`, `music.js`, `skills.js`, `release.js` генеруються. Правити генератор та вихідні адаптери, потім запускати побудову. Оригінальні файли за межами `beta/` не редагуються.

Тести DOM і програмного 3D не замінюють огляд WebGL у браузері. Показники FPS не слід заявляти без реального вимірювання. Для вимірювання є параметр `?perf=1` та дані `#homowPerformance` у DOM.

Оновлення 0.6.1: торговці мають окремі цивільні моделі та професійні інструменти. Атака тільки ЛКМ; кнопка атаки прихована. На мінікарті прибрано текстову плашку, назва регіону залишається вгорі екрана.
